    • Édition rapide
    Qu'est-ce que l'édition rapide ?
    Il s'agit de modifier certaines données essentielles de l'application sans avoir besoin de décompiler et de reconstruire.
    À quoi sert l'édition rapide ?
  • pour consulter les informations sur l'application (apk), ses autorisations et l'emplacement d'installation préféré (à ne pas confondre avec l'emplacement d'installation réel) ;
  • pour changer le nom de l'application ;
  • pour changer le nom du paquet de l'application (cloner l'application) ;
  • pour remplacer les icônes vectorielles (générées automatiquement), adaptatives et raster classiques dans les applications ;
  • pour définir l'emplacement d'installation préféré de l'application ;
  • pour modifier la version minimale ou cible du SDK ;
  • pour adapter l'application à Android TV ;
  • pour le retirer du Manifest : android:isSplitRequired, android:debuggable, android:testOnly.
    • Pourquoi ai-je besoin de l'élément « Autorisations » ?
    Pour consulter les autorisations de l'application, ainsi que pour les activer ou les désactiver.
    Puis-je convertir des images en vecteur ?
    Oui.
    Les formats PNG, Jpeg, Webp et Svg sont pris en charge.
    La conversion s'effectue en utilisant {old file name}type _vector.xml
    Lors de la conversion, vous pouvez améliorer ou dégrader la qualité de l'image.
    Est-il possible de convertir une image svg en VectorDrawable ?
    Oui.
    Disponible dans l'aperçu des polygones SVG/VectorDrawable (non compilés)
    Remarque : le svg doit avoir une structure simple et adéquate, sinon l'analyseur peut mal le traiter et vous devrez le normaliser manuellement pour qu'il fonctionne correctement.
    Est-il possible de convertir des images bitmap en VectorDrawable ?
    Oui.
    Ce n'est pas une panacée. Le tracé peut avoir une erreur importante : cela dépend de la complexité de la géométrie de l'image source.
    Comment remplacer l'icône de l'application ?
    1. Préparez l'icône nécessaire, de préférence au format png et d'une taille, si possible, d'au plus 192x192px.
    2. Sélectionnez l'application requise → Édition rapide.
    3. Dans le coin supérieur gauche, vous voyez l'icône de l'application installée et son nom.
    4. Appuyez sur l'icône elle-même et sélectionnez l'icône préparée auparavant.
    5. Si nécessaire, cochez les cases de réglages : « remplacer l'icône adaptative » « icône haute qualité (taille plus grande) »
    6. Sélectionnez également le fichier de signature si vous ne l'avez pas installé auparavant.
    7. Appuyez sur « Enregistrer ».
    Le fichier fini se trouvera dans le même dossier, à côté de l'application sélectionnée, avec le libellé mod à la fin.
    Comment extraire l'icône de l'application ?
    1. Sélectionnez l'application requise → Édition rapide.
    2. Appui long sur l'icône.
    L'icône extraite se trouvera dans le même dossier, à côté de l'application sélectionnée.
    Comment modifier la version minimale ou cible du sdk ?
    1. Sélectionnez l'application requise → Édition rapide.
    2. Effectuez les modifications nécessaires dans les réglages « Version minimale du SDK » ou « Version cible du SDK ».
    3. Appuyez sur « Enregistrer ».
    Le fichier fini se trouvera dans le même dossier, à côté de l'application sélectionnée, avec le libellé mod à la fin.
    Comment modifier le nom de l'application ?
    1. Sélectionnez l'application requise → Édition rapide.
    2. Ensuite, changez le nom de l'application souhaitée.
    3. Sélectionnez le fichier de signature si vous ne l'avez pas installé auparavant.
    4. Appuyez sur « Enregistrer ».
    Le fichier fini sera placé à côté de l'application sélectionnée, avec mod à la fin.
    Pourquoi ne puis-je pas modifier le « Nom de l'application » ? (L'élément est inactif.)
    Probablement parce que la version minimale du sdk de l'application est supérieure à celle de votre système. Dans ces conditions, l'édition est limitée.
    Vous devez d'abord abaisser la version minimale du sdk, puis modifier le reste.
    Comment modifier le nom du paquet de l'application ?
    1. Sélectionnez l'application requise → « Édition rapide ».
    2. Ensuite, changez le nom du paquet.
    3. Sélectionnez le fichier de signature si vous ne l'avez pas installé auparavant.
    4. Appuyez sur « Enregistrer ».
    Le fichier fini sera placé à côté de l'application sélectionnée, avec mod à la fin.
    Comment créer un clone apk dans cette application ?
    1. Sélectionnez l'application requise → « Édition rapide ».
    2. Puis changez le nom du paquet, par exemple en ajoutant ou en supprimant les dernières lettres du nom.
    3. Sélectionnez le fichier de signature si vous ne l'avez pas installé auparavant.
    4. Appuyez sur « Enregistrer ».
    Le fichier fini sera placé à côté de l'application sélectionnée, avec mod à la fin.
    Comment cloner une application pendant l'édition rapide ?
    Le programme modifie les paramètres suivants pendant l'édition rapide : AndroidManifest.xml et resources.arsc.
    Comment adapter l'application à Android TV ?
    1. Sélectionnez l'application requise → « Édition rapide ».
    2. Ensuite, cochez la case « Adapter pour Android TV ».
    3. Sélectionnez le fichier de signature si vous ne l'avez pas installé auparavant.
    4. Appuyez sur « Enregistrer ».
    Le fichier fini sera placé à côté de l'application sélectionnée, avec mod à la fin. L'icône de l'application est utilisée comme bannière.
    Que dois-je faire si l'application ne s'installe pas après une édition rapide ?
    Avez-vous vérifié que vous n'avez tout simplement pas signé le paquet ?
    Dans l'édition rapide, sélectionnez une signature. Par défaut, choisissez « ne pas signer » si vous n'avez pas utilisé la signature auparavant.
    Édition complète - décompilation et assemblage
    Qu'est-ce que la décompilation et à quoi sert-elle ?
    décompiler arsc+dex : traduit le code binaire en un format lisible. Nécessaire pour modifier les ressources de l'application (resources.arsc) et l'assembleur Smali (code). Et aussi pour les fonctions qui exigent cette décompilation : accéder aux informations, appliquer des correctifs, traduire...

    La recompilation nécessite la présence des binaires aapt. La demande d'installation apparaît au premier lancement de l'application. Si vous ne l'avez pas fait, le téléchargement se fait dans « Paramètres » Compilation et décompilation « Remplacer les outils » Télécharger pour ... »

    Comment décompiler l'application ?
    1. Sélectionnez l'application requise.
    2. Appuyez dessus.
    3. Un menu contextuel s'ouvre.
    4. Sélectionnez « Décompiler ».
    5. Nous cochons les éléments à décompiler :
      • « Décompiler les ressources »
      • « Décompiler classes.dex » ou « Décompiler tous les fichiers *.dex ».
        (L'élément « tous les *.dex » concerne les dex dans les dossiers imbriqués : par exemple dans assets, mthook, etc.)
      • Et aussi, si nécessaire, « Décompiler les ressources supplémentaires » avec choix de l'emplacement.
    Après une décompilation réussie, il y aura une notification audio et une boîte de dialogue, si elles étaient activées auparavant dans les Paramètres.
    Comment recompiler l'application ?
    1. Dans le projet, appuyez sur l'étiquette « Compiler le projet » au-dessus de la fenêtre de l'explorateur.
    2. Dans la fenêtre de compilation, sélectionnez l'outil de ressources : aapt ou aapt2.
    3. Vous pouvez aussi indiquer la signature automatique, si nécessaire.
    Le journal s'affiche en temps réel. Vous pouvez suivre les étapes, commentaires et erreurs pendant la compilation.
    À la fin, le journal s'arrêtera (ce sera visible).
    Après une compilation réussie, il y aura une notification audio et une boîte de dialogue, si elles étaient activées auparavant dans les Paramètres.
    En bas, il vous sera aussi proposé d'installer immédiatement l'application compilée.
    Où l'application est-elle enregistrée après la compilation ?
    Dans le dossier de l'application désassemblée. À la racine du projet (à côté de apktool.json)
    Est-il possible de décompiler plusieurs fichiers simultanément ?
    Oui, mais il vaut mieux décompiler plusieurs fichiers l'un après l'autre, car une décompilation simultanée peut manquer de mémoire.

    Comment faire ?
    Sélectionnez plusieurs fichiers et faites un appui long pour ouvrir le menu.
    Attention ! Cela fonctionne pour des fichiers du même type. Si autre chose qu'un apk est sélectionné, le menu ne contiendra aucun élément.
    Comment changer le dossier où les apk seront enregistrés ?
    1. Paramètres → « Compilation et décompilation » → « Définir le répertoire de sortie des applications installées »
    2. Allez dans le dossier souhaité, appuyez sur la ligne « chemin » pour définir le répertoire de sortie.
    3. Vous pouvez aussi définir le dossier de sortie directement dans le gestionnaire de fichiers.
    Qu'est-ce que l'élément « Répertoire de sortie des applications installées » ?
    C'est le répertoire où les APK seront exportés/extraits pour continuer le travail depuis le menu Applications.
    Comment remplacer des ressources dans le fichier « .apk » ?
    Il faut d'abord décompiler, puis copier/coller des fichiers et compiler.
    Que dois-je faire si l'application ne se compile pas, alors que tout a été fait sans erreurs, ou que je n'ai rien changé dans l'apk et que j'ai seulement recompilé ?
    Changez la version de aapt.
    Consultez le journal au niveau d'événement Warning.
    En général, regardez le journal : la raison devrait y être indiquée.
    Quelle est la compatibilité avec les projets Apktool ?
    Apktool M permet de compiler des projets analysés via l'Apktool habituel.
    Avant la compilation, Apktool M convertit .yml en .json.
    Vous pouvez suivre les informations sur le processus à l'aide du journal.

    Chemin de base : /system/framework/..

    Ils peuvent aussi se trouver dans /system/vendor/framework, etc., dans des répertoires adjacents. Si ces répertoires existent (cas rare).

    Exemple de frameworks :

    Puis décompilez et compilez comme un apk normal. Pour conserver le META-INF et le manifest d'origine, activez le bouton radio « Correspondre à l'original » dans les paramètres de décompilation.

    Explication des points de la section « Compilation et décompilation »
    Dossier de sortie
    Le chemin où les applications installées seront exportées/extraites depuis l'onglet « Applications ».
    Utiliser aapt2
    Ajoute la seconde version de l'outil à l'élément de sélection de version aapt avant la compilation.
    Informations de débogage

    Lors de la compilation, les données de débogage sont stockées dans les fichiers Smali, telles que.line, .param, etc.

    Remarque :
    Ces données sont requises uniquement pour déboguer l'application en mode débogable. Et aussi pour un débogage ciblé des plantages Smali dans Logcat (cas rare ; cela peut servir d'ancre à la ligne qui provoque le plantage). Elles n'affectent pas l'exécution du code. Ces données peuvent aussi aider lors de l'édition de l'assembleur Smali comme points de repère (pour les modeleurs).
    Mode débogage
    Écrit <application /> la valeur de l'attribut dans le manifest, dans la balise android:debuggable à true. Informe le système qu'il s'agit d'une application de débogage. Permet d'étendre l'accès aux journaux de cette application. L'interaction avec cette fonction n'est possible qu'avec des outils spéciaux (comme Android Studio, ainsi que le débogage au niveau ADB, etc.). Cette option ne s'applique pas à Logcat : le nombre d'entrées de débogage dans le journal système ne changera pas si ce paramètre est modifié.

    Pour indiquer une telle application comme application actuelle de débogage, sélectionnez-la dans « Paramètres système » Pour les développeurs « Application de débogage » (les chemins peuvent différer).

    Complet
    Pendant la compilation, affiche dans le journal l'état final de chacun des fichiers après compilation. Ne l'activez pas si vous n'en avez pas besoin.
    Correspondre à l'original
    Permet de conserver le hash original de META-INF et du manifest en respectant les hashs originaux des ressources.
    Ce mode permet d'éditer uniquement Smali : si vous essayez de compiler le fichier modifié dans res/..., il sera supprimé dans l'apk final, car il ne correspond pas au hash original (modifié).

    Cette question doit être clarifiée.

    Analyse de tout Smalisedit
    Accélère l'analyse des fichiers dans Smali.
    Ajouter « APKTOOL_DUMMY »

    Par défaut, les ID de ressources dans resources.arsc sont définis en progression arithmétique. Dans certains cas, elle peut être rompue : certains emplacements dans les types de valeurs peuvent ne pas être remplis (ils sont inoccupés).

    Ces emplacements sont remplis avec le stub APKTOOL_DUMMY pour restaurer l'intégrité de la progression. Ces lignes ne sont utilisées par personne et n'affectent rien.

    Petite remarque :

    Si vous supprimez un objet de ressource de res/values/public.xml, lors de la compilation, le programme essaiera de trouver un tel espace libre et d'y placer son ID. S'il n'y a pas de places disponibles, il sera ajouté à la fin de la liste des éléments de sa catégorie. Il n'est pas recommandé de le faire avec des ID d'objets spécifiés dans Smali : cela provoquera un plantage, car la ressource indiquée par ID a été déplacée (elle n'existe plus en tant que telle).

    Supprimer public.xml forcera Apktool à créer une progression depuis zéro : alors APKTOOL_DUMMY ne sera installé nulle part, car il n'y a pas d'espaces libres entre l'ID de début et de fin.

    Le besoin d'APKTOOL_DUMMY est déterminé uniquement par l'utilisateur. Cela peut aussi être nécessaire si le projet décompilé a une structure spécifique parmi les ID (en particulier à cause d'attributs personnalisés et/ou d'obfuscation).

    Formater HTML
    Le contenu de tous les fichiers .html et .htm (?) sera formaté selon la syntaxe XML. Cela peut perturber l'affichage de la page HTML. À n'activer qu'en cas de nécessité.
    Supprimer le dossier « build »

    Pendant la compilation, les fichiers DEX et ARSC sont mis en cache dans le dossier build. Si vous n'avez pas modifié les ressources après la compilation précédente et que vous recompilez l'apk, .arsc ne sera pas recréé, mais repris de l'instance en cache, car son hash est identique (non modifié). Cela s'applique aussi à Smali (fichiers DEX). Accélère la compilation de l'apk en sautant la recompilation.

    Supprimer un dossier ne fait que libérer de l'espace. Ensuite, lors de la compilation suivante, .dex et .arsc seront recréés « de zéro » et le dossier sera recréé. Activer cette option permet de supprimer automatiquement un dossier après une compilation réussie. Activez-la si vous le souhaitez.

    Tout vers le répertoire de sortie
    Tous les apk compilés avec succès seront automatiquement déplacés vers le répertoire de sortie ci-dessus.
    Gérer les frameworks
    Permet de gérer les frameworks importés de l'extérieur. Le bouton de réinitialisation efface la liste et les fichiers localement, et restaure aussi res-framework.apk (ID 1) depuis Apktool M.
    Traduction des applications
    Combien de langues sont prises en charge pour la traduction ?
    Plus de 100 langues.
    Quelles options sont disponibles dans Yandex.Translate ?
  • Traduction automatique des chaînes sélectionnées dans les ressources (strings, arrays, plurals) et smali ;
  • Traduction manuelle dans les ressources (strings, arrays, plurals) et smali ;
  • Correction de la traduction ;
  • Traduction en ligne avec choix de plusieurs services de traduction ;
  • Traduction hors ligne ;
  • Prise en charge des dictionnaires ;
  • Création de vos propres dictionnaires à partir d'une traduction existante ;
  • Prise en charge des dictionnaires MT Manager ;
  • Combinaison des langues.
    • Combien de services de traduction en ligne sont disponibles dans l'application ?
    Trois : Yandex, Google, Bing.
    Je ne trouve pas la fonction de traduction de l'application. Comment activer Yandex.Translate et traduire l'application (strings.xml) en russe ?
    Cette fonction n'est disponible que lorsque l'application est décompilée.
    1. Décompilez les ressources de l'apk souhaité.
    2. Allez dans le dossier des fichiers décompilés.
    3. Ouvrez le menu du gestionnaire de fichiers (il s'ouvre en appuyant sur la barre d'adresse) et sélectionnez « Traducteur ».
    Comment traduire une application automatiquement ?
    1. Décompilez les ressources de l'apk souhaité.
    2. Allez dans le dossier des fichiers décompilés.
    3. Ouvrez le menu du gestionnaire de fichiers (il s'ouvre en appuyant sur la barre d'adresse) et sélectionnez l'élément « Traducteur », puis appuyez sur les trois points en haut à droite et sélectionnez « Traduction automatique ».
    4. Dans le menu qui s'ouvre, sélectionnez le service de traduction souhaité, par exemple Yandex.
    5. Dans l'élément « Langue source », vous pouvez laisser « Détecter la langue » ; pour la sélection automatique de la langue finale, choisissez celle souhaitée. Par défaut, la langue installée sur votre système est proposée.
    6. En bas, cochez les cases nécessaires « Fusionner s'il existe » ou « Enregistrer uniquement les chaînes traduites »
    7. Sélectionnez les lignes nécessaires.
    8. Appuyez sur « Traduire » pour traduire les chaînes dans res/values/strings.
    9. Après la fin du transfert, appuyez à nouveau sur les trois points en haut à droite et sélectionnez « Enregistrer »
    10. Nous compilons notre projet (application).
    Comment traduire une application en smali automatiquement ?
    1. Décompilez l'apk souhaité.
    2. Allez dans le dossier des fichiers décompilés.
    3. Ouvrez le menu du gestionnaire de fichiers (il s'ouvre en appuyant sur la barre d'adresse) et sélectionnez « traduction smali », puis appuyez sur les trois points en haut à droite et sélectionnez « Traduction automatique ».
    4. Dans le menu qui s'ouvre, sélectionnez le service de traduction souhaité, par exemple Yandex.
    5. Dans l'élément « Langue source », vous pouvez laisser « Détecter la langue » ; pour la sélection automatique de la langue finale, choisissez celle souhaitée. Par défaut, la langue installée sur votre système est proposée.
    6. Sélectionnez les lignes nécessaires.
    7. En bas, cochez les cases nécessaires « Fusionner s'il existe » ou « Enregistrer uniquement les chaînes traduites »
    8. Appuyez sur « Traduire »
    9. Après la fin du transfert, appuyez à nouveau sur les trois points en haut à droite et sélectionnez « Enregistrer ».
    10. Nous compilons notre projet (application).
    Dans « Traduction automatique », il y a une fonction « corriger la traduction ». À quoi sert-elle ?
    Pour ignorer les lignes que vous n'avez pas besoin de traduire : true, false, %1$d/%2$d, inclut désormais aussi les graphiques vectoriels, les références, etc., et corrige certaines lignes après la traduction automatique.
    Comment traduire une application manuellement ?
    1. Décompilez l'apk souhaité.
    2. Allez dans le dossier des fichiers décompilés.
    3. Ouvrez le menu du gestionnaire de fichiers (il s'ouvre en appuyant sur la barre d'adresse) et sélectionnez « traduction smali » puis modifiez manuellement les lignes nécessaires.
    4. En haut à droite, appuyez sur les trois points et sélectionnez « Enregistrer »
    5. Nous compilons notre projet (application).
    Comment combiner des langues si les chaînes par défaut de l'application traduite ne contiennent pas celles nécessaires, mais que d'autres les ont ?
    Après la traduction nécessaire de l'application, allez dans le menu du traducteur, sélectionnez « ajouter, ajouter depuis » et ajoutez les lignes manquantes d'une autre locale. Bien sûr, nous les traduisons ensuite si nécessaire.
    Quel format de dictionnaire est pris en charge dans Apktool M ?
    *.amd et *.mtd
    Comment créer mon propre dictionnaire à partir d'un fichier traduit ?
    Ouvrez Yandex.Translate, sélectionnez « créer un dictionnaire » dans le menu, sélectionnez la source (chaînes non traduites) et la ressource cible (votre fichier de traduction) dans le dossier du projet, et enregistrez.
    Comment utiliser le dictionnaire enregistré ?
    La prochaine fois que vous ferez un transfert, il apparaîtra dans la sélection des services de traduction.
    Où puis-je obtenir un dictionnaire prêt pour la traduction hors ligne ?
    Dans le sujet MT Manager
    Copiez-le vers « Répertoire de sortie/dictionary » (par défaut « Apktool_M/dictionary » dans la mémoire interne), ou importez-le simplement en appuyant sur le fichier du dictionnaire dans le programme et en l'ajoutant.
    Ensuite, le dictionnaire apparaîtra dans Yandex.Translate, dans les services de traduction automatique.
    Après le transfert, le projet n'est pas collecté. Une erreur est renvoyée.
    1. Supprimez les lignes invalides généralement indiquées dans le journal d'erreur de compilation.
    2. Pour compiler, utilisez aapt1 s'il ne se compile pas avec aapt2 et qu'il n'y a pas d'erreurs sur des chaînes de traduction invalides.
    3. L'application peut être protégée par signature.
    Fonction Antisplit
    Qu'est-ce qu'un Antisplit ?
    Il s'agit de fusionner l'Android App Bundle (split) en un seul fichier d'installation, ainsi que d'installer et d'extraire de tels fichiers.
    Comment compiler un apk à partir de splits ? Où se trouve cette option ?
    1. Dans le menu contextuel « Antisplit ». Appelé par un appui court sur apks/xapk.
    2. Dans le menu contextuel « Antisplit ». Appelé en appuyant sur un groupe d'apk présélectionnés / sélectionnés.
    Ensuite, sélectionnez l'outil de compilation nécessaire : aapt2 ou aapt, si l'application ne se compile pas d'abord.
    Puis-je compiler un apk à partir du split installé ?
    Oui.
    Nous sélectionnons l'application installée dans la liste des applications et, par un appui long, appelons l'élément « Antisplit ».
    Où se trouve le fichier collecté ?
    L'apk se trouve dans le dossier de travail par défaut : internal_memory/Apktool_M.
    À la fin de la compilation, il y aura un bouton « Installer », mais un appui long ouvrira le dossier contenant le fichier.
    Instructions pas à pas pour convertir des Apks en Apk avec Apktool M.
    1. Sélectionnez le fichier souhaité (Apks) et appuyez dessus.
    2. Puis sélectionnez « Antisplit » dans le menu qui apparaît.
    3. Puis appuyez à nouveau sur le bouton « Antisplit » (assurez-vous d'abord que tous les fichiers, c'est-à-dire toutes les cases, sont activés).
    4. Ensuite, sélectionnez l'outil souhaité (aapt2 ou aapt si l'application n'est pas compilée) et appuyez sur le bouton « Sélectionner ».
    5. Attendez la fin de tout le processus.
    Votre Apks est maintenant devenu un Apk, et vous pouvez travailler avec comme avec un fichier Apk normal.
    Créer une signature personnalisée
    Comment créer ma signature ?

    Allez dans « Paramètres » → « Signature », sélectionnez « Créer une clé ».

  • Dans les paramètres de signature, vous pouvez définir le nom des fichiers RSA/SF, ainsi que le nom du créateur pour la signature V1

    • Dans le menu qui s'ouvre, remplissez les lignes suivantes :

    Algorithme de signature :
    Différence dans la longueur du hash du certificat (après signature de l'apk). SHA256withRSA est optimal. Nous le laissons par défaut. MD5 est considéré comme peu sûr. Les différences détaillées se trouvent sur Internet.

    Type :
    Spécifie le type de stockage. Par défaut, JKS (aussi connu sous le nom de .keystore). Les différences détaillées se trouvent sur Internet.

    Chemin vers la clé :
    Emplacement de sortie du stockage de la clé. Le nom du fichier est saisi automatiquement, et vous pouvez le modifier à la fin si vous le souhaitez.

    Alias :
    Alias de la clé. Indiqué lors de l'importation/l'utilisation.

    Mot de passe du stockage et de la clé :
    Mot de passe pour protéger le stockage et la clé elle-même avant de l'importer/l'utiliser. Par commodité, vous pouvez les rendre identiques.

    Taille de clé :
    Spécifie le nombre de bits (longueur) de la signature de la clé. La valeur par défaut est 2048. Augmenter la taille augmente sa force cryptographique, mais l'analyse est plus difficile (plus lente). Défini selon une progression géométrique informative (2, 4, 8, 16, 32, 64, 128, 256, 512, 1024, 2048, 4096, etc.)

    Période de validité :
    Le temps à compter de la date de création après lequel l'authenticité de la clé expire. Indiqué en années.

    Les informations suivantes servent à renseigner le propriétaire de la signature. Indiquez-les si vous le souhaitez :
    Nom, poste, organisation, ville, région/État, pays.

    Le bouton « Enregistrer » termine la création et place le magasin de clés au chemin indiqué auparavant.

    Le bouton « Créer et utiliser » importe en plus le fichier final à la place de la signature utilisateur.

    Gestionnaire de fichiers
    Apktool a-t-il un gestionnaire de fichiers complet ?
    Oui.
    Comment accéder au menu du gestionnaire de fichiers ?
    Le menu s'ouvre en appuyant sur la barre d'adresse.
    Quelles fonctionnalités a-t-il ?
  • suppression de fichiers ;
  • copie ;
  • renommage, y compris par lots ;
  • création d'une liste de fichiers ;
  • archivage ;
  • propriétés des fichiers et dossiers ;
  • recherche complète ;
  • signets ;
  • historique des derniers fichiers ouverts ;
  • la boîte de dialogue des propriétés du fichier apk/apks est un sujet à part ;
  • aperçu des fichiers xml/svg vectoriels, ainsi que conversion d'images en vecteur ;
  • aperçu des polices ttf/otf ;
  • opérations par lots sur les apk ou images sélectionnés, par appui long ;
  • dans les dossiers du projet, dans les propriétés des fichiers de ressources, se trouve leur ID issu de public.xml (s'il y en a).
    • Comment ouvrir le menu contextuel lors de la visualisation des fichiers ?
    Appui long sur le fichier lui-même.

    • Comment sélectionner un fichier / dossier ?
    1. Appui long sur le fichier / dossier lui-même ou sur l'icône.
    2. Après avoir sélectionné un fichier / dossier par appui long sur l'icône, vous pouvez faire un appui long sur l'icône d'un autre fichier pour sélectionner les fichiers « de et jusqu'à ».
    3. Vous pouvez aussi tout sélectionner rapidement par appui long sur l'icône « retour » (..)
    Comment renommer des fichiers ?
    Par appui long sur le fichier, la boîte de dialogue de renommage apparaît.
    Dans la même boîte, par appui long sur « auto », vous pouvez renommer en mode automatique à l'aide de modèles.
    Comment modifier un fichier avec un éditeur externe directement depuis l'application ?
    Appui long sur le fichier → dans le menu contextuel, sélectionnez « Ouvrir dans »...
    Comment créer une archive de fichiers ?
    Sélectionnez « Compresser » dans le menu contextuel. Lors de l'archivage, vous pouvez les ajouter à une archive existante.
    Puis-je supprimer ou remplacer des fichiers/dossiers dans des archives (y compris les APK) sans les désassembler/assembler ?
    Oui.
    1. Appui long sur l'archive /.apk et sélectionnez « Voir le contenu » dans le menu contextuel.
    2. Utilisez un appui long pour sélectionner ce que vous devez supprimer ou extraire.
    Après les manipulations nécessaires, le fichier sera automatiquement réassemblé et signé.
    Le fichier original est enregistré à côté avec l'extension .bak.
    Comment remplacer un fichier ou un dossier par un déjà modifié dans un APK désassemblé ?
    Appui long sur le fichier souhaité et sélectionnez « Extraire ici » dans le menu contextuel...
    Si vous voulez, par exemple, remplacer une image dans le dossier drawable, vous devez ajouter au apk le dossier res contenant le remplacement, qui contient le dossier drawable, qui contient à son tour l'image.

    Autrement dit, il est important de conserver la structure des répertoires !

    Après les actions nécessaires, nous archivons à nouveau le fichier avec l'extension apk.
    Nous le signons.
    Apktool M a-t-il un moteur de recherche complet ?
    Oui.
    Il y a la recherche de fichiers, de noms de fichiers, de texte dans les fichiers, et d'applications installées.
    La saisie manuelle d'adresse se déclenche par un appui long sur l'adresse.
    L'application a-t-elle une recherche par expressions régulières ?
    Oui.
    Comment commencer à utiliser la recherche ?
    Ouvrez le menu du gestionnaire de fichiers en appuyant sur l'adresse.
    Je n'ai pas trouvé de recherche de dossier. Seulement dans le fichier.
    Il ne faut pas maintenir le dossier lui-même, mais entrer dans le dossier où se fera la recherche, puis appuyer sur la « flèche ou le chemin vers le dossier/fichier » et le menu de recherche apparaîtra.
    Tous les résultats de recherche sont-ils enregistrés et comment les trouver ?
    Oui. L'historique de recherche est enregistré.
    Un élément apparaît dans le menu de l'Explorateur (appuyez sur l'adresse en haut), ou par appui long sur l'icône de recherche du panneau inférieur, si elle y est activée.
    Vous pouvez aussi rechercher dans les résultats de recherche eux-mêmes.
    Si vous n'avez rien recherché, cet élément est absent.

    Comment retirer les langues inutiles de l'application, sauf ru, eng ?
    Dans le menu contextuel, sélectionnez l'élément « Optimiser (aapt2) ».

    Comment retirer toutes les langues sauf le russe, l'ukrainien et l'anglais ?
    Semblable à la suppression de toutes les langues sauf le russe et l'anglais.
    Dans l'élément « Définir la configuration », indiquez les langues à conserver, par exemple « ru, ru-rRU, uk, ru-rUA, uk-rRU ».

    Comment mettre à jour Apktool M ?
    Écran d'accueil → Trois points dans le coin supérieur droit → « Paramètres » → « Mise à jour du programme » activez « Rechercher des mises à jour ».
    Plus bas, vous pouvez sélectionner l'élément « Fréquence de vérification des mises à jour ».
    Comment télécharger la mise à jour ?
    Depuis Apktool M lui-même, ou téléchargez via le navigateur.
    Où le fichier de mise à jour est-il enregistré ?
    Dans la mémoire interne, dans le dossier « Download ».
    Puis-je désactiver la vérification des mises à jour ?
    Oui, vous le pouvez.

    Écran d'accueil → Trois points dans le coin supérieur droit → « Paramètres » → « À propos de l'application » → « Désactiver la vérification des mises à jour ».

    Comment restaurer à partir d'une sauvegarde ? Mon élément de restauration n'est pas actif...
    Pour récupérer, vous devez d'abord enregistrer votre compte.
    Le fichier de sauvegarde doit se trouver au chemin : « /internal_memory/Apktool_M. backup » ; s'il est absent, l'élément n'est pas actif.
    MPatcher
    Qu'est-ce que MPatcher ?
    C'est une application pour exécuter, créer, importer et exporter des scripts et correctifs écrits en Shell, intégrée dans Apktool M.
    Y a-t-il un sujet séparé sur le forum ?
    Oui : MPatcher
    Comment appeler MPatcher ?
    Appui long sur le fichier et sélectionnez « MPatcher » dans le menu contextuel qui s'ouvre.
    Cela indiquera l'apk cible.

    Pour sélectionner le projet cible, au-dessus de « Compiler » se trouve un menu déroulant, il y a un élément MPatcher.
