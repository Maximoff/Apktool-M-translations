    • 快速編輯
    什麼是快速編輯？
    這是在不需要反編譯和重建的情況下編輯一些核心應用程式資料。
    快速編輯是做什麼用的？
  • 查看有關應用程式（APK）、其權限和首選安裝位置的資訊（不要與實際安裝位置混淆）；
  • 更改應用程式名稱；
  • 更改應用包名稱（克隆應用）；
  • 取代應用程式中的矢量（自動生成）、自適應和常規光柵圖示；
  • 設定首選應用程式安裝位置；
  • 更改最低或目標 SDK 版本；
  • 使應用程式適配 Android TV；
  • 從清單中移除：android:isSplitRequired、android:debuggable、 android:testOnly。
    • 為什麼我需要「權限」項？
    查看應用程式的權限，以及啟用或禁用這些權限。
    我可以將圖像轉換為矢量嗎？
    可以。
    支援 PNG、Jpeg、Webp 和 Svg 格式
    轉換使用的類型為 {old file name}_vector.xml
    轉換時，您可以提高或降低圖像品質。
    是否可以將 svg 圖像轉換為 VectorDrawable？
    可以。
    在 SVG/VectorDrawable 多邊形預覽版（未編譯）中可用
    注意： SVG 必須具有簡單且足夠的結構，否則解析器可能無法正確處理它，您就得手動對其進行規範化才能使其正常工作。
    是否可以將位圖圖像轉換為 VectorDrawable？
    可以。
    這不是靈丹妙藥。它可能在跟蹤時有很大的誤差 - 這取決於源圖像幾何結構的複雜性。
    如何取代應用程式圖示？
    1. 準備必要的圖示，最好是 png 格式和尺寸不超過 192x192px。
    2. 選擇所需的應用程式 → 快速編輯。
    3. 在左上角，您可以看到已安裝應用程式的圖示及其名稱。
    4. 點擊圖示本身並選擇先前準備的圖示。
    5. 如有必要，請選中必要的設定框：「取代自適應圖示」、「高品質圖示（較大尺寸）」
    6. 如果之前沒有安裝過，請選擇簽名檔案。
    7. 點擊「儲存」。
    完成的檔案將與所選的應用程式在同一個資料夾中，並緊挨著，且末尾帶有 mod 標籤字樣。
    如何提取應用程式圖示？
    1. 選擇所需的應用程式 → 快速編輯。
    2. 長按圖示。
    提取的圖示將與所選的應用程式在同一個資料夾中，並緊挨著。
    如何更改最低或目標 SDK 版本？
    1. 選擇所需的應用程式 → 快速編輯。
    2. 對「最低SDK版本」或「目標SDK版本」設定進行必要的更改。
    3. 點擊「儲存」。
    完成的檔案將與所選的應用程式在同一個資料夾中，並緊挨著，且末尾帶有 mod 標籤字樣。
    如何更改應用名稱？
    1. 選擇所需的應用程式 → 快速編輯。
    2. 接下來，將所需應用程式的名稱更改為所需的名稱。
    3. 如果之前沒有安裝過，請選擇簽名檔案。
    4. 點擊「儲存」。
    完成的檔案將被放置在選定的應用程式旁邊，並在末尾標記 mod 字樣。
    為什麼我無法更改「應用名稱」？（該專案處於非活動狀態。）
    可能是因為應用程式的最低 SDK 版本高於您的系統版本。在這些條件下，編輯受到限制。
    首先，您需要降級 SDK 的最低版本，然後編輯其他所有內容。
    如何更改應用包名稱？
    1. 選擇所需的應用程式 → 「快速編輯」。
    2. 接下來，更改程式包名稱。
    3. 如果之前沒有安裝過，請選擇簽名檔案。
    4. 點擊「儲存」。
    完成的檔案將被放置在選定的應用程式旁邊，並在末尾標記 mod 字樣。
    如何在此應用程式中進行 apk 克隆？
    1. 選擇所需的應用程式 → 「快速編輯」。
    2. 然後更改包名稱，例如在名稱的最後新增或刪除一個字母。
    3. 如果之前沒有安裝過，請選擇簽名檔案。
    4. 點擊「儲存」。
    完成的檔案將被放置在選定的應用程式旁邊，並在末尾標記 mod 字樣。
    如何在快速編輯過程中克隆應用程式？
    該程式在快速編輯過程中更改以下參數：AndroidManifest.xml 和 resources.arsc。
    如何使應用程式適配 Android TV？
    1. 選擇所需的應用程式 → 「快速編輯」。
    2. 接下來，選中「適配 Android TV」。
    3. 如果之前沒有安裝過，請選擇簽名檔案。
    4. 點擊「儲存」。
    完成的檔案將被放置在選定的應用程式旁邊，並在末尾標記 mod 字樣。應用程式圖示被用作於橫幅。

    檢查是否沒有對安裝包進行簽名？
    在快速編輯中，選擇一個簽名。預設情況下，如果您以前沒有使用過簽名，請選擇「不簽名」。
    完全編輯 - 反編譯和彙編
    什麼是反編譯，它的用途是什麼？
    反編譯 arsc + dex —— 將二進位程式碼轉換為人類可讀的格式。在編輯應用程式資源（resources.arsc）和 Smali 彙編程式（程式碼）時是必需的。也適用於需要這種反編譯的函式 —— 用於存取資訊、應用補丁、翻譯...

    要使重新編譯正常工作，需要 aapt 的二進位檔案。首次啟動應用時，系統會提示您安裝。如果沒有，請到「設定 » 編譯 » 更換工具」中下載 ... "

    如何反編譯應用程式？
    1. 選擇所需的應用。
    2. 點擊它。
    3. 將開啟一個彈出選單。
    4. 選擇「反編譯」。
    5. 我們標記需要反編譯的專案：
      • 「反編譯資源」
      • 「反編譯 classes.dex」或「反編譯所有 *.dex 檔案"
        （「所有 *.dex」項負責子資料夾中的 dex：例如 assets、mthook 等）
      • 此外，如有必要，還可以選擇反編譯的位置進行「反編譯額外資源」。
    反編譯成功後，如果之前在「設定」中啟用了音訊和對話框通知，則會出現該通知。
    如何編譯回應用程式？
    1. 在專案中，點一下資源管理器窗口上方的「編譯此專案」標籤。
    2. 在編譯窗口中，選擇資源構建工具 aapt 或 aapt2。
    3. 如有必要，還可以指定自動簽名。
    紀錄是實時顯示的。您可以在構建過程中跟蹤階段、注釋和錯誤。
    完成後，紀錄將停止（這將是可見的）。
    編譯成功後，如果之前在「設定」中啟用了音訊和對話框通知，則會出現該通知。
    在底部，系統還會提示您立即安裝構建的應用程式。
    應用程式構建後儲存在哪裡？
    到包含已反編譯應用程式的資料夾。在專案根目錄中（apktool.json 旁邊）
    是否可以同時反編譯多個檔案？
    可以，但最好連續反編譯幾個，因為如果同時反編譯，可能會記憶體不足。

    怎麼做？
    選擇多個檔案並長按以開啟選單。
    注意！ 這適用於相同類型的檔案。如果選擇了 apk 以外的內容，則選單將不包含任何專案。
    如何更改儲存 apk 的資料夾？
    1. 設定 → 「編譯」 → 「匯出目錄」
    2. 轉到所需的資料夾，點擊「路徑」行 - 設為匯出目錄。
    3. 您也可以直接在檔案管理器中設定輸出檔案夾。
    什麼是「已安裝應用程式的輸出目錄」專案？
    這是從「應用程式」選單中匯出/提取 APK 以進行進一步工作的目錄。
    如何取代「.apk」檔案中的資源？
    首先您需要反編譯，然後複製/貼上檔案並構建。
    如果儘管一切都沒有錯誤，或者我根本沒有更改 apk 中的任何內容，只是重新編譯，但應用程式沒有構建，我該怎麼辦？
    切換 aapt 版本。
    查看「警告」事件級別的紀錄。
    一般來說，請查看紀錄 - 在那裡應該有指出原因。

    偵錯模式
    將清單中 <application /> 標籤裡的 android:debuggable 屬性值設為 true。 通知系統它是一個偵錯應用程式。允許您擴展存取此應用程式的紀錄記錄。只有在特殊工具（例如 Android Studio，以及 ADB 級別的偵錯等）的說明下，才能與該函式的功能進行交互。此選項不適用於 Logcat - 如果更改此參數，系統紀錄中的偵錯條目數不會改變。

    若要將此類應用程式指定為目前要偵錯的應用程式，請在「系統設定」的開發者選項中「偵錯應用」裡選擇它（路徑可能會有所不同）。

    詳細
    在構建過程中，它會在編譯每個檔案之後將其最終狀態輸出到紀錄中。如果不需要，請不要啟用它。
    匹配原始檔
    允許您通過鑑於原始資源雜湊來儲存原始 META-INF 和清單雜湊。
    此模式僅允許您編輯 Smali – 如果您嘗試在 res/... 中構建編輯後的檔案，它將在最終的 apk 中被刪除，因為它與原始雜湊（已修改）不匹配。

    這個問題需要作出清楚的說明。

    分析所有 Smali
    加快 Smali 中的檔案分析速度。
    新增「APKTOOL_DUMMY」

    預設情況下，resources.arsc 中的資源 ID 是按等差數列設定的。在某些情況下，它可能已損壞 - 值類型中的某些位置可能不會被填充（未佔用）。

    這些位置是從 APKTOOL_DUMMY 樁程式碼設定的，以恢復數列的完整性。這些行不被任何人使用，也不影響任何東西。

    小提示：

    如果從 res/values/public.xml 中刪除了一個資源物件，那麼在構建期間，它將嘗試找到一個可用空位，並在其中設定其 ID。如果沒有可用位置，它將被新增到其類別中專案列表的末尾。不建議使用 Smali 中指定的物件 ID 執行此操作 - 這將會導致當機，因為 ID 指定的資源已移動（不再存在）。

    完全刪除 public.xml 將迫使 Apktool 從頭開始建立一個數列 – 因為起始和結束 ID 之間沒有可用空位，然後 APKTOOL_DUMMY 將不會安裝到任何地方。

    對 APKTOOL_DUMMY 的需求完全由使用者決定。如果反編譯專案在 ID 之間具有特定的結構（特別是由於自訂屬性和(或)程式碼混淆），則也可能需要這樣做。

    格式化 HTML
    所有 .html 和 .htm(?) 檔案的內容將根據 XML 語法進行格式化。這可能會破壞 HTML 頁面的輸出顯示。只有在必要時才安裝。
    刪除「build」資料夾

    在構建期間，DEX 和 ARSC 檔案會快取在「build」資料夾中。如果在上一次構建之後未修改資源並重新構建 apk，那麼 .arsc 將不會再次建立，而是從快取的實例中提取，因為它的雜湊值是相同的（未修改）。這也適用於 Smali（DEX 檔案）。通過跳過重新編譯來加快 apk 的構建速度。

    刪除資料夾只會釋放空間。之後，在下一次構建期間，.dex 和 .arsc 將「從頭開始」重新建立，資料夾將被重新建立。激活此選項可使您在成功構建後自動刪除資料夾。如果需要，請激活它。

    全部到輸出目錄
    所有成功編譯的 apk 將自動遷移到上述輸出目錄。
    管理框架
    允許您管理從外部匯入的框架。點擊重設按鈕可清除列表和本機檔案本身，並從 Apktool M 恢復 res-framework.apk（ID 1）。
    翻譯應用程式
    支援多少種語言的翻譯？
    超過 100 種語言。
    在 Yandex 翻譯中有哪些選項可用？
  • 自動翻譯資源（strings、arrays、plurals）和 smali 中選定的字串；
  • 手動翻譯資源（strings、arrays、plurals）和 smali；
  • 更正譯文；
  • 線上翻譯有多種翻譯服務可供選擇；
  • 離線翻譯；
  • 字典支援；
  • 根據現有的翻譯建立自己的字典；
  • 支援 MT 管理器字典；
  • 組合語言。
    • 此應用程式中有多少線上翻譯服務？
    三個：Yandex、Google、Bing。
    我找不到此應用程式的翻譯功能。如何啟用 Yandex 翻譯並將應用程式（strings.xml）翻譯成漢語？
    此功能僅在應用程式反編譯時可用。
    1. 反編譯所需 apk 的資源。
    2. 轉到包含反編譯檔案的資料夾。
    3. 開啟檔案管理器選單（點一下地址欄開啟），並選擇「翻譯模式」。
    如何自動翻譯應用程式？
    1. 反編譯所需 apk 的資源。
    2. 轉到包含反編譯檔案的資料夾。
    3. 開啟檔案管理器選單（點一下地址欄開啟），並選擇「翻譯模式」，然後點一下右上角的三個點，並選擇「自動翻譯」。
    4. 在開啟的選單中，選擇所需的翻譯服務，例如 Yandex。
    5. 在「源語言」項中，您可以保留選擇「自動檢測」 目標語言 - 選擇所需語言。預設情況下，建議使用系統上安裝的語言。
    6. 在底部，選中「如果存在則合併」或「僅儲存翻譯後的字串」這些必要的選項
    7. 選擇必要的行並選擇它們。
    8. 點擊「翻譯」以翻譯 res/values/strings 中的字串。
    9. 完成後，再次點一下右上角的三個點，然後選擇「儲存」
    10. 整合專案（應用程式）。
    如何在 smali 中自動翻譯應用程式？
    1. 反編譯所需的 apk。
    2. 轉到包含反編譯檔案的資料夾。
    3. 開啟檔案管理器選單（點一下地址欄開啟），並選擇「翻譯 Smali」，然後點一下右上角的三個點，並選擇「自動翻譯」。
    4. 在開啟的選單中，選擇所需的翻譯服務，例如 Yandex。
    5. 在「源語言」項中，您可以保留選擇「自動檢測」 目標語言 - 選擇所需語言。預設情況下，建議使用系統上安裝的語言。
    6. 選擇必要的行並選擇它們。
    7. 在底部，選中「如果存在則合併」或「僅儲存翻譯後的字串」這些必要的選項
    8. 點擊「翻譯」
    9. 完成後，再次點一下右上角的三個點，然後選擇「儲存」
    10. 整合專案（應用程式）。
    在「自動翻譯」中，有一個「糾正翻譯」的功能。它是做什麼用的？
    跳過不需要翻譯的行：true、false、%1$d/%2$d，現在還包括矢量圖形、引用等，並在自動翻譯後更正一些行。
    如何手動翻譯應用程式？
    1. 反編譯所需的 apk。
    2. 轉到包含反編譯檔案的資料夾。
    3. 開啟檔案管理器選單（點一下地址欄開啟），並選擇「翻譯 Smali」，然後手動編輯必要的行。
    4. 在右上角，點一下三個點，然後選擇「儲存」
    5. 整合專案（應用程式）。
    如果翻譯後的應用程式預設字串不包含必要的字串，而其他字串包含，我該如何組合語言？
    在對應用程式進行必要的翻譯後，轉到翻譯選單，選擇「新增，選擇來源」，然後新增來自其他語言環境的缺失行。當然，如有必要，我們會翻譯它們。
    Apktool M 支援什麼字典格式？
    *.amd 和 *.mtd
    如何從翻譯檔案建立自己的字典？
    開啟 Yandex 翻譯，從選單中選擇「建立字典」，在專案資料夾中選擇源資源（未翻譯的字串）和目標資源（您的翻譯檔案），然後儲存。
    如何使用儲存的字典？
    下次進行翻譯時，它將出現在翻譯服務選項中。
    我在哪裡可以得到現成的字典進行離線翻譯？
    在 MT 管理器話題 中
    將其複製到「輸出目錄/dictionary」（預設情況下，它在內部儲存空間的「Apktool_M/dictionary」中），或者只需點一下程式中的字典檔案匯入並新增即可。
    之後，該字典將出現在 Yandex 翻譯的自動翻譯服務中。
    翻譯後，專案未整合。返回錯誤。
    1. 刪除通常在編譯錯誤紀錄中指出的無效內容。
    2. 如果不是在 aapt2 中構建的，且沒有關於無效翻譯字串的錯誤，請使用 aapt1 進行構建。
    3. 該應用程式可能受到簽名保護。
    合併分包功能
    什麼是合併分包？
    這是將 Android App Bundle（分包）合併為一個安裝檔案，以及安裝和提取此類檔案。
    如何從分包中構建 apk？此選項位於何處？
    1. 在上下文選單中的「合併分包」。只需在 apks/xapk 上短按即可調用。
    2. 在上下文選單中的「合併分包」。通過點擊一組預選/選定的 apk 來調用。
    接下來，如果沒有先構建應用程式，請選擇必要的編譯工具：aapt2 或 aapt。
    我可以從已安裝的分包中構建 apk 嗎？
    可以。
    在應用程式列表中選擇已安裝的應用程式，然後長按調出「合併分包」項。
    收集的檔案位於何處？
    APK 位於預設的工作資料夾「內部儲存空間/Apktool_M」中。
    在構建結束時，會有一個「安裝」按鈕，但如果長按它，則會開啟包含此檔案的資料夾。
    有關如何使用 Apktool M 將 Apks 轉換為 Apk 的分步說明。
    1. 選擇所需的檔案（Apks）並點一下它。
    2. 然後從出現的選單中選擇「合併分包」。
    3. 然後再次點擊「合併分包」按鈕（首先確保所有檔案，即所有複選框都已啟用）。
    4. 之後，選擇所需的工具（aapt2 或 aapt，如果應用程式未編譯），然後點一下「選擇」按鈕。
    5. 等待整個過程完成。
    現在您的 Apks 已經變成了一個 Apk，可以像使用普通的 Apk 檔案一樣使用它。
    建立自訂簽名
    如何建立我的簽名？

    進入「設定」→「簽名」，選擇「建立金鑰」。

  • 在簽名設定中，您可以設定 RSA/SF 檔案的名稱，以及 V1 簽名的建立者姓名

    • 在開啟的選單中，填寫以下行：

    簽名算法：
    憑證 Hash 算法的長度差異（在對 apk 進行簽名後）。SHA256withRSA 是最佳選擇。我們預設保留它。MD5 被認為是不安全的。詳細的差異可以在網際網路上找到。

    金鑰類型：
    指定金鑰庫類型。預設指定為 JKS（也可稱為 .keystore）。詳細的差異可以在網際網路上找到。

    金鑰路徑：
    金鑰的輸出儲存位置。檔案名稱是自動輸入的，如有需要，您可以在末尾進行更改。

    別名：
    金鑰的別名。在匯入/操作期間指定。

    金鑰庫和金鑰密碼：
    在匯入/使用金鑰之前，用密碼保護金鑰庫和金鑰本身。為了方便起見，您可以使它們完全相同。

    金鑰大小：
    指定要讀取的金鑰簽名的位數（長度）。預設值為2048。增加大小會增加其加密強度，但分析起來更困難（速度較慢）。使用資訊幾何級數設定（2、4、8、16、32、64、128、256、512、1024、2048、4096，依此類推）

    有效期：
    從建立日期算起，金鑰的真實性到期的時間。以年為單位。

    需要以下資訊來通知您有關簽名所有者的資訊。根據需要指定：
    姓名、職位、組織、城市、地區/省、國家。

    點擊「儲存」按鈕完成建立，並將金鑰庫放置於先前指定的路徑中。

    點擊「建立並使用」按鈕還將匯入最終檔案以代替使用者簽名。

    是否可以將 jks/keystore 金鑰庫轉換為 pk8私鑰+X509憑證？
    是的，有可能。

    MPatcher
    什麼是 MPatcher？
    它是一個用於運行、建立、匯入、匯出用 Shell 編寫的腳本和補丁的應用程式，集成在 Apktool M 中。
    論壇上是否有單獨的話題？
    有的：MPatcher
    如何調用 MPatcher？
    長按檔案，並在開啟的上下文選單中選擇「MPatcher」。
    這將指定目標 apk。

    在目標專案「編譯此專案」上面有一個下拉選單，其中有一個 MPatcher 專案。
