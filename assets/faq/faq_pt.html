    • Edição rápida
    O que é edição rápida?
    É a edição de alguns dados principais do aplicativo sem a necessidade de descompilar e reconstruir.
    Para que serve a edição rápida?
  • para ver informações sobre o aplicativo (apk), suas permissões e o local de instalação preferido (não confundir com o local de instalação real);
  • para alterar o nome do aplicativo;
  • para alterar o nome do pacote do aplicativo (clonar o aplicativo);
  • para substituir ícones vetoriais (gerados automaticamente), adaptativos e raster comuns nos aplicativos;
  • para definir o local de instalação preferido do aplicativo;
  • para alterar a versão mínima ou de destino do SDK;
  • para adaptar o aplicativo ao Android TV;
  • para removê-lo do Manifest: android:isSplitRequired, android:debuggable, android:testOnly.
    • Para que serve o item «Permissões»?
    Para ver as permissões do aplicativo, bem como ativá-las ou desativá-las.
    Posso converter imagens para vetor?
    Sim.
    Os formatos PNG, Jpeg, Webp e Svg são suportados.
    A conversão ocorre usando {old file name}type _vector.xml
    Ao converter, você pode melhorar ou piorar a qualidade da imagem.
    É possível converter uma imagem svg para VectorDrawable?
    Sim.
    Disponível na pré-visualização de polígonos SVG/VectorDrawable (não compilados)
    Nota: o svg deve ter uma estrutura simples e adequada; caso contrário, o analisador pode não processá-lo corretamente e você terá de o normalizar manualmente para que funcione bem.
    É possível converter imagens bitmap para VectorDrawable?
    Sim.
    Isto não é uma panaceia. Pode haver um erro grande no traçado — depende da complexidade da geometria da imagem de origem.
    Como substituo o ícone do aplicativo?
    1. Prepare o ícone necessário, de preferência em formato png e com tamanho, de preferência, não superior a 192x192px.
    2. Selecione o aplicativo desejado → Edição rápida.
    3. No canto superior esquerdo, você vê o ícone do aplicativo instalado e o respectivo nome.
    4. Toque no próprio ícone e selecione o ícone preparado anteriormente.
    5. Se necessário, marque as caixas de definições: «substituir ícone adaptativo» «ícone de alta qualidade (tamanho maior)»
    6. Selecione também o arquivo de assinatura se ainda não o tiver instalado.
    7. Toque em «Salvar».
    O arquivo pronto ficará na mesma pasta, ao lado do aplicativo selecionado, com o rótulo mod no final.
    Como extraio o ícone do aplicativo?
    1. Selecione o aplicativo desejado → Edição rápida.
    2. Toque longo no ícone.
    O ícone extraído ficará na mesma pasta, ao lado do aplicativo selecionado.
    Como altero a versão mínima ou de destino do sdk?
    1. Selecione o aplicativo desejado → Edição rápida.
    2. Faça as alterações necessárias nas definições «Versão mínima do SDK» ou «Versão de destino do SDK».
    3. Toque em «Salvar».
    O arquivo pronto ficará na mesma pasta, ao lado do aplicativo selecionado, com o rótulo mod no final.
    Como altero o nome do aplicativo?
    1. Selecione o aplicativo desejado → Edição rápida.
    2. Em seguida, altere o nome do aplicativo para o desejado.
    3. Selecione o arquivo de assinatura se ainda não o tiver instalado.
    4. Toque em «Salvar».
    O arquivo pronto será colocado ao lado do aplicativo selecionado, com mod no final.
    Por que não consigo alterar o «Nome do aplicativo»? (O item está inativo.)
    Provavelmente porque a versão mínima do sdk do aplicativo é superior à do seu sistema. Nestas condições, a edição é restringida.
    Primeiro é preciso reduzir a versão mínima do sdk e depois editar o resto.
    Como altero o nome do pacote do aplicativo?
    1. Selecione o aplicativo desejado → «Edição rápida».
    2. Em seguida, altere o nome do pacote.
    3. Selecione o arquivo de assinatura se ainda não o tiver instalado.
    4. Toque em «Salvar».
    O arquivo pronto será colocado ao lado do aplicativo selecionado, com mod no final.
    Como faço um clone apk neste aplicativo?
    1. Selecione o aplicativo desejado → «Edição rápida».
    2. Depois altere o nome do pacote, por exemplo adicionando ou removendo as últimas letras do nome.
    3. Selecione o arquivo de assinatura se ainda não o tiver instalado.
    4. Toque em «Salvar».
    O arquivo pronto será colocado ao lado do aplicativo selecionado, com mod no final.
    Como clono um aplicativo durante a edição rápida?
    O programa altera os seguintes parâmetros durante a edição rápida: AndroidManifest.xml e resources.arsc.
    Como adapto o aplicativo ao Android TV?
    1. Selecione o aplicativo desejado → «Edição rápida».
    2. Em seguida, marque a caixa «Adaptar para Android TV».
    3. Selecione o arquivo de assinatura se ainda não o tiver instalado.
    4. Toque em «Salvar».
    O arquivo pronto será colocado ao lado do aplicativo selecionado, com mod no final. O ícone do aplicativo é usado como banner.
    O que devo fazer se o aplicativo não instalar após uma edição rápida?
    Verificou se simplesmente não assinou o pacote?
    Na edição rápida, selecione uma assinatura. Por predefinição, escolha «não assinar» se ainda não tiver usado a assinatura.
    Edição completa - descompilação e montagem
    O que é a descompilação e para que serve?
    descompilar arsc+dex: traduz o código binário para um formato legível. Necessário para editar os recursos do aplicativo (resources.arsc) e o assembler Smali (código). E também para funções que exigem esta descompilação: aceder a informações, aplicar patches, traduzir...

    A recompilação requer os binários do aapt. O pedido de instalação aparece no primeiro arranque do aplicativo. Se não o tiver feito, a transferência é feita em «Definições» Compilar e descompilar «Substituir ferramentas» Transferir para ... »

    Como descompilo o aplicativo?
    1. Selecione o aplicativo desejado.
    2. Toque nele.
    3. Abre-se um menu pop-up.
    4. Selecione «Descompilar».
    5. Marcamos os itens que precisam ser descompilados:
      • «Descompilar recursos»
      • «Descompilar classes.dex» ou «Descompilar todos os arquivos *.dex».
        (O item «todos os *.dex» é responsável pelos dex em pastas aninhadas: por exemplo, em assets, mthook, etc.)
      • E também, se necessário, «Descompilar recursos adicionais» com escolha de onde descompilar.
    Após uma descompilação bem-sucedida, haverá uma notificação de áudio e um diálogo, se tiverem sido ativados previamente nas Definições.
    Como compilo o aplicativo de volta?
    1. Dentro do projeto, toque no rótulo «Compilar projeto» acima da janela do explorador.
    2. Na janela de compilação, selecione a ferramenta de recursos: aapt ou aapt2.
    3. Também pode indicar a assinatura automática, se necessário.
    O registo é mostrado em tempo real. Pode acompanhar etapas, comentários e erros durante o processo de compilação.
    Ao terminar, o registo irá parar (isso será visível).
    Após uma compilação bem-sucedida, haverá uma notificação de áudio e um diálogo, se tiverem sido ativados previamente nas Definições.
    Na parte inferior também será pedido para instalar imediatamente o aplicativo compilado.
    Onde o aplicativo é salvo após ser compilado?
    Na pasta do aplicativo desmontado. Na raiz do projeto (ao lado de apktool.json)
    É possível descompilar vários arquivos simultaneamente?
    Sim, mas é melhor descompilar vários em sequência, porque se descompilar simultaneamente pode não haver memória suficiente.

    Como se faz?
    Selecione vários arquivos e faça um toque longo para abrir o menu.
    Atenção! Isto funciona para arquivos do mesmo tipo. Se for selecionado algo que não seja apk, o menu não conterá itens.
    Como altero a pasta onde os apk serão salvos?
    1. Definições → «Compilar e descompilar» → «Definir diretório de saída dos aplicativos instalados»
    2. Vá à pasta desejada, toque na linha «caminho» e defina o diretório de saída.
    3. Também pode definir a pasta de saída diretamente no gerenciador de arquivos.
    O que é o item «Diretório de saída dos aplicativos instalados»?
    É o diretório onde os APK serão exportados/extraídos para trabalho posterior a partir do menu Aplicativos.
    Como substituo recursos no arquivo «.apk»?
    Primeiro precisa descompilar e depois copiar/colar arquivos e compilar.
    O que devo fazer se o aplicativo não compilar, embora tudo tenha sido feito sem erros, ou se eu não alterei nada no apk e apenas recompilei?
    Mude a versão do aapt.
    Veja o registo no nível de evento Warning.
    Em geral, olhe para o registo — o motivo deve estar indicado lá.

    Antes de compilar, o Apktool M converte .yml em .json.
    Pode acompanhar informações sobre o processo usando o registo.

    Informações de depuração

    Ao compilar, os dados de depuração são armazenados em arquivos Smali, tais como.line, .param, e assim por diante.

    Nota:
    Estes dados são necessários apenas para depurar o aplicativo em modo depurável. E também para depuração pontual de falhas Smali no Logcat (ocorrência rara; pode servir de âncora à linha que causa a falha). Não afetam a execução do código. Estes dados também podem ajudar ao editar o assembler Smali como pontos de referência (para modeladores).
    Modo de depuração
    Escreve <application /> o valor do atributo no manifest, na etiqueta android:debuggable para true. Notifica o sistema de que é um aplicativo de depuração. Permite alargar o acesso ao registo deste aplicativo. A interação com esta função só é possível com ferramentas especiais (como o Android Studio, bem como depuração ao nível ADB, etc.). Esta opção não se aplica ao Logcat — o número de entradas de depuração no registo do sistema não mudará se este parâmetro for alterado.

    Para indicar esse aplicativo como o atual para depuração, selecione-o em «Definições do sistema» Para programadores «Aplicativo de depuração» (os caminhos podem diferir).

    Completo
    Durante a compilação, mostra no registo o estado final de cada um dos arquivos após ser compilado. Não ative se não precisar.
    Corresponder ao original
    Permite guardar o hash original de META-INF e do manifest respeitando os hashes originais dos recursos.
    Este modo permite editar apenas Smali — se tentar compilar o arquivo editado em res/..., ele será eliminado no apk final, porque não corresponde ao hash original (modificado).

    Análise de todo Smalisedit
    Acelera a análise de arquivos em Smali.
    Adicionar «APKTOOL_DUMMY»

    Por predefinição, os IDs de recursos dentro de resources.arsc são definidos em progressão aritmética. Em alguns casos, pode estar quebrada — alguns lugares dentro dos tipos de valor podem não estar preenchidos (estão desocupados).

    Esses lugares são preenchidos com o stub APKTOOL_DUMMY para restaurar a integridade da progressão. Essas linhas não são usadas por ninguém e não afetam nada.

    Uma pequena nota:

    Se eliminar um objeto de recurso de res/values/public.xml, durante a compilação tentará encontrar esse espaço livre e definir o respetivo ID nele. Se não houver lugares disponíveis, será adicionado no final da lista de itens da sua categoria. Não é recomendado fazer isto com IDs de objetos especificados em Smali — causará uma falha, porque o recurso especificado por ID foi movido (já não existe como tal).

    Eliminar public.xml forçará o Apktool a criar uma progressão do zero — então o APKTOOL_DUMMY não será instalado em lado nenhum, porque não há espaços livres entre o ID inicial e o final.

    A necessidade de APKTOOL_DUMMY é determinada apenas pelo utilizador. Também pode ser necessário se o projeto descompilado tiver uma estrutura específica entre os IDs (em particular, devido a atributos personalizados e/ou ofuscação).

    Formatar HTML
    O conteúdo de todos os arquivos .html e .htm (?) será formatado de acordo com a sintaxe XML. Isto pode perturbar a apresentação da página HTML. Instala-se apenas se necessário.
    Eliminar a pasta «build»

    Durante a compilação, os arquivos DEX e ARSC são colocados em cache na pasta build. Se não alterou os recursos após a compilação anterior e voltou a compilar o apk, o .arsc não será criado novamente, mas será obtido da instância em cache, porque o respetivo hash é idêntico (não modificado). Isto também se aplica a Smali (arquivos DEX). Acelera a compilação do apk ao saltar a recompilação.

    Eliminar uma pasta apenas liberta espaço. Depois, na compilação seguinte, .dex e .arsc serão recriados «do zero» e a pasta será recriada. Ativar esta opção permite eliminar automaticamente uma pasta após uma compilação bem-sucedida. Ative se desejar.

    Tudo para o diretório de saída
    Todos os apk compilados com sucesso serão automaticamente migrados para o diretório de saída acima.
    Gerir frameworks
    Permite gerir frameworks importados do exterior. O botão de repor limpa a lista e os próprios arquivos localmente, e também restaura res-framework.apk (ID 1) a partir do Apktool M.
    Traduzir aplicativos
    Quantos idiomas são suportados para tradução?
    Mais de 100 idiomas.
    Que opções estão disponíveis no Yandex.Translate?
  • Tradução automática de cadeias selecionadas em recursos (strings, arrays, plurals) e smali;
  • Tradução manual em recursos (strings, arrays, plurals) e smali;
  • Correção da tradução;
  • Tradução online com escolha de vários serviços de tradução;
  • Tradução offline;
  • Suporte a dicionários;
  • Criar os seus próprios dicionários a partir de uma tradução existente;
  • Suporte a dicionários do MT Manager;
  • Combinar idiomas.
    • Quantos serviços de tradução online estão disponíveis no aplicativo?
    Três: Yandex, Google, Bing.
    Não encontro a função de tradução do aplicativo. Como ativar o Yandex.Translate e traduzir o aplicativo (strings.xml) para russo?
    Esta funcionalidade só está disponível quando o aplicativo está descompilado.
    1. Descompile os recursos do apk desejado.
    2. Vá à pasta com os arquivos descompilados.
    3. Abra o menu do gerenciador de arquivos (abre-se ao tocar na barra de endereço) e selecione «Tradutor».
    Como traduzo um aplicativo automaticamente?
    1. Descompile os recursos do apk desejado.
    2. Vá à pasta com arquivos descompilados.
    3. Abra o menu do gerenciador de arquivos (abre-se ao tocar na barra de endereço) e selecione o item «Tradutor», depois toque nos três pontos no canto superior direito e selecione «Tradução automática».
    4. No menu que abre, selecione o serviço de tradução desejado, por exemplo Yandex.
    5. No item «Idioma de origem» pode deixar «Detetar idioma»; na seleção automática do idioma final, escolha o desejado. Por predefinição, sugere-se o idioma instalado no seu sistema.
    6. Na parte inferior, marque as caixas necessárias «Unir se existir» ou «Salvar apenas cadeias traduzidas»
    7. Selecione as linhas necessárias.
    8. Toque em «Traduzir» para traduzir cadeias em res/values/strings.
    9. Após concluir a transferência, toque novamente nos três pontos no canto superior direito e selecione «Salvar»
    10. Compilamos o nosso projeto (aplicativo).
    Como traduzo um aplicativo em smali automaticamente?
    1. Descompile o apk desejado.
    2. Vá à pasta com arquivos descompilados.
    3. Abra o menu do gerenciador de arquivos (abre-se ao tocar na barra de endereço) e selecione «tradução smali», depois toque nos três pontos no canto superior direito e selecione «Tradução automática».
    4. No menu que abre, selecione o serviço de tradução desejado, por exemplo Yandex.
    5. No item «Idioma de origem» pode deixar «Detetar idioma»; na seleção automática do idioma final, escolha o desejado. Por predefinição, sugere-se o idioma instalado no seu sistema.
    6. Selecione as linhas necessárias.
    7. Na parte inferior, marque as caixas necessárias «Unir se existir» ou «Salvar apenas cadeias traduzidas»
    8. Toque em «Traduzir»
    9. Após concluir a transferência, toque novamente nos três pontos no canto superior direito e selecione «Salvar».
    10. Compilamos o nosso projeto (aplicativo).
    Em «Tradução automática» há uma função «corrigir tradução». Para que serve?
    Para saltar linhas que não precisa traduzir: true, false, %1$d/%2$d, agora também inclui gráficos vetoriais, referências, etc., e corrige algumas linhas após a tradução automática.
    Como traduzo um aplicativo manualmente?
    1. Descompile o apk desejado.
    2. Vá à pasta com arquivos descompilados.
    3. Abra o menu do gerenciador de arquivos (abre-se ao tocar na barra de endereço) e selecione «tradução smali» e edite manualmente as linhas necessárias.
    4. No canto superior direito, toque nos três pontos e selecione «Salvar»
    5. Compilamos o nosso projeto (aplicativo).
    Como posso combinar idiomas se as cadeias predefinidas do aplicativo traduzido não contiverem as necessárias, mas outras sim?
    Após a tradução necessária do aplicativo, vá ao menu do tradutor, selecione «adicionar, adicionar de» e adicione as linhas em falta de outra locale. Claro, depois traduzimo-las se necessário.
    Que formato de dicionário é suportado no Apktool M?
    *.amd e *.mtd
    Como crio o meu próprio dicionário a partir de um arquivo traduzido?
    Abra o Yandex.Translate, selecione «criar dicionário» no menu, selecione a origem (cadeias não traduzidas) e o recurso de destino (o seu arquivo de tradução) na pasta do projeto, e salve.
    Como uso o dicionário salvo?
    Na próxima vez que fizer uma transferência, aparecerá na seleção de serviços de tradução.
    Onde posso obter um dicionário pronto para tradução offline?
    No tópico do MT Manager
    Copie-o para «Diretório de saída/dictionary» (por predefinição é «Apktool_M/dictionary» na memória interna), ou simplesmente importe-o tocando no arquivo do dicionário no programa e adicione-o.
    Depois disso, o dicionário aparecerá no Yandex.Translate, nos serviços de tradução automática.
    Após a transferência, o projeto não é recolhido. Devolve um erro.
    1. Elimine as linhas inválidas que normalmente são indicadas no registo de erro de compilação.
    2. Para compilar, use aapt1 se não for compilado com aapt2 e não houver erros sobre cadeias de tradução inválidas.
    3. O aplicativo pode estar protegido por assinatura.
    Função Antisplit
    O que é um Antisplit?
    É a fusão do Android App Bundle (split) num único arquivo de instalação, bem como a instalação e extração desses arquivos.
    Como compilar um apk a partir de splits? Onde está esta opção?
    1. No menu de contexto «Antisplit». Chamado com um toque curto em apks/xapk.
    2. No menu de contexto «Antisplit». Chamado ao tocar num grupo de apk pré-selecionados / selecionados.
    Em seguida, selecione a ferramenta de compilação necessária: aapt2 ou aapt, se o aplicativo não for compilado primeiro.
    Posso compilar um apk a partir do split instalado?
    Sim.
    Selecionamos o aplicativo instalado na lista de aplicativos e, com um toque longo, chamamos o item «Antisplit».
    Onde está o arquivo recolhido?
    O apk está na pasta de trabalho predefinida: internal_memory/Apktool_M.
    No fim da compilação haverá um botão «Instalar», mas se o mantiver premido durante muito tempo, a pasta com o arquivo será aberta.
    Instruções passo a passo para converter Apks em Apk com o Apktool M.
    1. Selecione o arquivo desejado (Apks) e toque nele.
    2. Depois selecione «Antisplit» no menu que aparece.
    3. Depois toque novamente no botão «Antisplit» (primeiro certifique-se de que todos os arquivos, ou seja, todas as caixas, foram ativados).
    4. Depois disso, selecione a ferramenta desejada (aapt2 ou aapt se o aplicativo não for compilado) e toque no botão «Selecionar».
    5. Aguarde a conclusão de todo o processo.
    Agora o seu Apks transformou-se num Apk, e pode trabalhar com ele como com um arquivo Apk normal.
    Criar uma assinatura personalizada
    Como crio a minha assinatura?

    Vá a «Definições» → «Assinatura», selecione «Criar chave».

  • Nas definições de assinatura, pode definir o nome dos arquivos RSA/SF, bem como o nome do criador para a assinatura V1

    • No menu que abre, preencha as seguintes linhas:

    Algoritmo de assinatura:
    Diferença no comprimento do hash do certificado (após assinar o apk). SHA256withRSA é o ideal. Deixamos o predefinido. MD5 é considerado inseguro. Diferenças detalhadas podem ser encontradas na Internet.

    Tipo:
    Especifica o tipo de armazenamento. Por predefinição, JKS (também conhecido como .keystore). Diferenças detalhadas podem ser encontradas na Internet.

    Caminho para a chave:
    Local de saída do armazenamento da chave. O nome do arquivo é introduzido automaticamente e pode alterá-lo no final se quiser.

    Alias:
    Alias da chave. Indicado durante a importação/operação.

    Palavra-passe do armazenamento e da chave:
    Palavra-passe para proteger o armazenamento e a própria chave antes de a importar/usar. Por conveniência, pode torná-las idênticas.

    Tamanho da chave:
    Especifica o número de bits (comprimento) da assinatura da chave. O valor predefinido é 2048. Aumentar o tamanho aumenta a sua força criptográfica, mas é mais difícil de analisar (mais lento). Definido com uma progressão geométrica informativa (2, 4, 8, 16, 32, 64, 128, 256, 512, 1024, 2048, 4096, etc.)

    Período de validade:
    O tempo a partir da data de criação em que a autenticidade da chave expira. Indicado em anos.

    As seguintes informações servem para informar sobre o proprietário da assinatura. Indique conforme desejar:
    Nome, cargo, organização, cidade, região/estado, país.

    O botão «Salvar» conclui a criação e coloca o armazenamento de chaves no caminho indicado anteriormente.

    O botão «Criar e usar» importa adicionalmente o arquivo final no lugar da assinatura do utilizador.

    • Como seleciono um arquivo / pasta?
    1. Toque longo no próprio arquivo / pasta ou no ícone.
    2. Após selecionar um arquivo / pasta com toque longo no ícone, pode fazer toque longo no ícone de outro arquivo para selecionar arquivos «de e até».
    3. Também pode selecionar tudo rapidamente com toque longo no ícone «voltar» (..)
    Como renomeio arquivos?
    Com toque longo no arquivo, aparece o diálogo de renomeação.
    No mesmo diálogo, com toque longo em «auto», pode renomear em modo automático usando modelos.
    Como posso editar um arquivo com um editor externo diretamente a partir do aplicativo?
    Toque longo no arquivo → no menu de contexto pop-up, selecione «Abrir em»...
    Como crio um arquivo de arquivos?
    Selecione «Comprimir» no menu de contexto. Ao arquivar arquivos, pode adicioná-los a um arquivo existente.
    Posso eliminar ou substituir arquivos/pastas em arquivos (incluindo APKs) sem os desmontar/montar?
    Sim.
    1. Toque longo no arquivo /.apk e selecione «Ver conteúdo» no menu pop-up.
    2. Use um toque longo para selecionar o que precisa eliminar ou extrair.
    Após as manipulações necessárias, o arquivo será automaticamente remontado e assinado.
    O arquivo original é salvo ao lado com a extensão .bak.
    Como posso substituir um arquivo ou pasta por um já editado num APK desmontado?
    Toque longo no arquivo desejado e selecione «Extrair aqui» no menu de contexto...
    Se quiser, por exemplo, substituir uma imagem na pasta drawable, deve adicionar ao apk a pasta res com a substituição, que contém a pasta drawable, que por sua vez contém a imagem.

    Por outras palavras, é importante preservar a estrutura de diretórios!

    Após as ações necessárias, arquivamos novamente o arquivo com extensão apk.
    Assinamo-lo.
    O Apktool M tem um motor de pesquisa completo?
    Sim.
    Há pesquisa de arquivos, de nomes de arquivos, de texto em arquivos e de aplicativos instalados.
    A introdução manual de endereço é acionada por toque longo no endereço.
    O aplicativo tem pesquisa por expressões regulares?
    Sim.
    Como começo a usar a pesquisa?
    Abra o menu do gerenciador de arquivos tocando no endereço.
    Não encontrei pesquisa de pasta. Só no arquivo.
    Não precisa manter a pasta, mas entrar na pasta onde a pesquisa será feita, depois tocar na «seta ou caminho para a pasta/arquivo» e o menu de pesquisa aparecerá.
    Todos os resultados de pesquisa são salvos e como os encontro?
    Sim. O histórico de pesquisa é salvo.
    Aparece um item no menu do Explorador (toque no endereço no topo), ou por toque longo no ícone de pesquisa no painel inferior, se estiver ativado aí.
    Também pode pesquisar nos próprios resultados de pesquisa.
    Se não pesquisou nada, este item está em falta.
    Diversos
    O Apktool tem uma função de clone?
    Sim.
    Isto requer uma descompilação completa do aplicativo.
    De que outra forma posso clonar um aplicativo?
    Use o patch no programa MPatcher.
    Como posso remover idiomas desnecessários do aplicativo, exceto ru, eng?
    No menu de contexto, selecione o item «Otimizar (aapt2)».
    Nas definições deste item, marque a caixa «Definir configuração» e indique o idioma que precisa deixar, neste caso «ru, ru-rRU».
    Como removo todos os idiomas exceto russo, ucraniano e inglês?
    Semelhante a eliminar todos os idiomas exceto russo e inglês.
    No item «Definir configuração», indique os idiomas que precisa deixar, por exemplo «ru, ru-rRU, uk, ru-rUA, uk-rRU».
    Como posso ver a lista de aplicativos instalados?
    No canto superior direito — o separador «Aplicativos».
    Como edito todo o Manifest no aplicativo?
    Todo o manifest é editado quando os recursos são descompilados.

    • Atenção!

    Todos os cifradores retrocompatíveis podem ser convertidos de volta. Isto é feito na janela de entrada inferior.
    Como atualizo o Apktool M?
    Ecrã inicial → Três pontos no canto superior direito → «Definições» → «Atualização do programa» ative «Verificar atualizações».
    Abaixo, pode selecionar o item «Frequência de verificação de atualizações».
    Como transfiro a atualização?
    Do próprio Apktool M, ou transfira pelo navegador.
    Onde o arquivo de atualização é salvo?
    Na memória interna, na pasta «Download».
    Posso desativar a verificação de atualizações?
    Sim, pode.

    Ecrã inicial → Três pontos no canto superior direito → «Definições» → «Acerca do aplicativo» → «Desativar verificação de atualizações».

    Como posso restaurar a partir de uma cópia de segurança? O meu item de restauro não está ativo...
    Para recuperar, primeiro deve salvar a sua conta.
    O arquivo de cópia de segurança deve estar no caminho: «/internal_memory/Apktool_M. backup»; se não estiver presente, o item não está ativo.
    MPatcher
    O que é o MPatcher?
    É um aplicativo para executar, criar, importar e exportar scripts e patches escritos em Shell, integrado no Apktool M.
    Há um tópico separado no Fórum?
    Sim: MPatcher
    Como chamo o MPatcher?
    Toque longo no arquivo e selecione «MPatcher» no menu de contexto que abre.
    Isto indicará o apk de destino.

    Para selecionar o projeto de destino — acima de «Compilar» há um menu pendente, há um item MPatcher.
